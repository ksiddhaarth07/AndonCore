# Security policy

AndonCore is a sandbox project. Do not send it real customer data, production credentials, or unredacted incident logs. The local web app is loopback-only and is not an authenticated production service.

## Reporting a vulnerability

Please report suspected vulnerabilities privately through GitHub's **Report a vulnerability** feature (Security Advisories) on the repository, if enabled. Do not open a public issue containing exploit details, credentials, account identifiers, or personal data. If private reporting is unavailable, contact the repository owner through their verified GitHub profile and share only the minimum details needed to establish contact.

Include the affected commit or version, impact, reproduction steps, and any suggested mitigation. Do not access or modify systems or data you do not own or have explicit permission to test.

This project does not currently publish a supported production release or a response-time commitment.
